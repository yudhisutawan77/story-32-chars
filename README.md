## The name

**She Left Me for Better WiFi**

## Why it is funny

She did not leave for another person — she left for better Wi-Fi.
One line implies the whole story: a relationship, a breakup, and a
punchline where the rival is a faster connection. The joke lands on
the first read, it names a character and something that happened, and
it is not one of the stock Wi-Fi jokes everyone has seen.

## Run

```sh
python3 main.py
```

The program writes exactly the name `She Left Me for Better WiFi`
(27 characters, no trailing newline) to the output file. It honours
`ENTRY_OUT` (a file path) first, then `ENTRY_OUT_DIR` (a directory
holding `entry.txt`), and defaults to `/output/entry.txt`. It prints
exactly the name to stdout and nothing else.
